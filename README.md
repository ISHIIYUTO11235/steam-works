# 汽械仕掛けの夜明け — Steam Logic Works

動力も制御も、すべて同じ蒸気で。
横スクロールのスチームパンク自動化ゲームです。小さな蒸気工場の社長として案件を受け、品物を納め、稼いだ金で設計書を買い足しながら、王立博覧会への自動人形の出展を目指します。

**▶ 遊ぶ：https://ishiiyuto11235.github.io/steam-works/**

ブラウザだけで動きます。インストールは不要で、PC でもスマホでも遊べます。

## 特徴

- **蒸気の圧で論理回路を組む**
  信号用の電線はありません。弁が蒸気の圧をそのまま通すか止めるかで、NOT・AND・XOR などの論理を組みます。
- **圧力を管理する**
  圧力は kPa（キロパスカル）で表します。ボイラーは最高 400 kPa、大型ボイラーは 1000 kPa。設備ごとに動かせる圧力の範囲があり、足りなくても強すぎても止まります。圧力を知る方法は、管に付けたアナログの圧力計の針を読むことだけ。減圧弁・安全弁・圧力スイッチ弁で、工場全体の圧力を組み立てます。
- **動力と信号が同じボイラーを取り合う**
  論理回路も蒸気を食います。信号の線に機械をつなげば圧が下がり、回路が誤作動することもあります。
- **重力のある横視点**
  ベルトの端から落とした品物は、下の設備やベルトへ落ちます。上へ運ぶときは昇降機を使います。地下を掘り進めれば、銅・原油・地下水が見つかります。
- **チップ**
  9×9 の盤に弁と管を組み、1マスの部品として鋳込めます。チップの中にチップを入れることもできます。
- **社長として経営する**
  全27件の案件に難易度（★1〜5）があります。納期・純度・定時便・交互納品などの条件付き案件は、回路で解くパズルになっています。最上級の案件では、チップの設計図そのものを納めます。

- **からくり福引き**
  「純銅の検品」を達成すると骨董商がやって来ます。1回 ¥500、10回 ¥4,500 で引けます。景品は全68種です。
  - 設備の見た目：46種
  - 景色：5種（ゲーム中の背景とホーム画面に、別々に設定できる）
  - BGM：5曲
  - 福引きでしか手に入らない設計書：12種

  10回続けて★3以上が出なければ、10回目で必ず出ます。持っている景品がまた出たら、お金に替えて返します。

## 基本ルール

1. **ボイラー**は水に隣接させ、燃料（石炭・木炭・灯油）を入れると、背後の管へ蒸気を送ります（最高 400 kPa）。
2. **圧力は管のマスごとに違います。** 蒸気は流れるほど圧が落ちるので、ボイラーから遠い設備ほど圧が低くなります。ボイラーを近くに足すか、太管に替えると改善します。ボイラーを増やして増えるのは蒸気の量で、上限の圧力は変わりません。
3. **設備**は、自分の背後を通る管から蒸気を受けて動きます。動かせる圧力の範囲（例：削岩機 150〜600 kPa、植物プラント 80〜250 kPa）から外れると止まり、頭上に赤い印が出ます。原因は近くの管に付けた圧力計の針で確かめ、強すぎるときは減圧弁で下げます。
4. **管**は、ドラッグで引いた向きにだけつながります。隣に並べただけでは混ざりません。交差させたいところは交差管を使います。
5. **弁**は、背中（入口）から矢印（出口）へ蒸気を通します。
   - 常閉弁：横の操作口に圧があるときだけ開く
   - 常開弁：横の操作口に圧があると閉じる
   - 閉じた弁は、出口側の蒸気を抜く
   - 100 kPa 以上を信号の「1」とみなす（遊びがあり、60 kPa を下回ると「0」に戻る）
6. **案件**の品を出荷口へ届けると報酬が入ります。本筋の依頼を片付けると、新しい設計書が買えるようになります。

### 回路の例

| 回路 | 組み方 |
|---|---|
| NOT | 常開弁の入口に給気の線、操作口に入力 A をつなぐ |
| AND | 常閉弁の入口に A、操作口に B をつなぐ |
| OR | 2本の線を逆止弁を通して合流させる |
| XOR | 常開弁を2つ使う。（入口 A・操作口 B）と（入口 B・操作口 A）の出口を合流させる |

| | PC | スマホ |
|---|---|---|
| 設置 | 左クリック（管・ベルトはドラッグで連続） | パレットから地図へドラッグ。連続で置くときは、選んでから地図を長押ししてなぞる |

## 仕分け機の作り方

秤弁と落とし戸ベルトを**同じマスに重ねる**だけです。秤弁で決めた品が乗ったときだけ床が開き、その品は真下へ落ちます。ほかの品はそのまま流れます。同じマスに重ねたベルトや設備は、管ではなく重ねた弁の出口から蒸気を受けます。

## セーブについて

進行はブラウザの localStorage に自動保存されます（8秒ごとと、タブを閉じたとき）。

- ブラウザのサイトデータを消すとセーブも消えます。
- 別のブラウザや別の端末とは共有されません。

## ローカルで動かす

`index.html` をブラウザで開くだけです。ビルドも依存ライブラリもありません。

```bash
git clone https://github.com/ISHIIYUTO11235/steam-works.git
cd steam-works
open index.html   # Windows は start index.html
```

## 開拓地（別ワールド）

「自動人形の出展」を納めると、メニューの「土地」から新しい土地を拓けます。地形（平原・丘陵・渓谷・湖沼）は拓くたびにランダムに生成され、最大8か所まで持てます。お金・設計書・チップ・案件・実績は全部の土地で共通です。

## 言語

日本語・English・简体中文・Português に対応しています（メニュー／ホームの「設定」で切り替え）。訳は `i18n/*.json` にあり、`python3 tools/build_i18n.py` で `index.html` に埋め込みます。`--missing` を付けると、訳のない文字列を一覧にします。

## 技術

- 1ファイルの HTML（Canvas 2D、素の JavaScript）
- ドット絵はすべてコード内で描画（16px）
- 効果音と BGM は Web Audio API でその場で合成
- 蒸気網は、管のつながりを Union-Find でまとめた区画ごとに、圧と流量を 0.1 秒刻みで計算

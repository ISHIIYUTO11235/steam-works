# 蒸気工廠 — Steam Logic Works

動力も制御も、すべて同じ蒸気で。
横スクロールのスチームパンク自動化ゲームです。小さな蒸気工場の社長として案件を受け、品物を納め、稼いだ金で設計書を買い足しながら、王立博覧会への自動人形の出展を目指します。

蒸気が動力であり出力そのものであるという面白いコンセプトかなと思います。蒸気は0か1ではなく気圧があり、それらを制御するのが肝です。
まあ既存の物にかなり近しいですが、チップを自由に作り関数化でき、さらにそのチップ別のチップに入れることもできるので、理論上CPUなどもつくれます。全加算器ができることは実験済みです。

**▶ 遊ぶ：https://ishiiyuto11235.github.io/steam-works/**

ブラウザだけで動きます。インストールは不要で、PC でもスマホでも遊べます。

## 特徴

- **蒸気の圧で論理回路を組む**
  信号用の電線はありません。弁が蒸気の圧をそのまま通すか止めるかで、NOT・AND・XOR などの論理を組みます。
- **動力と信号が同じボイラーを取り合う**
  論理回路も蒸気を食います。信号の線に機械をつなげば圧が下がり、回路が誤作動することもあります。
- **重力のある横視点**
  ベルトの端から落とした品物は、下の設備やベルトへ落ちます。上へ運ぶときは昇降機を使います。地下を掘り進めれば、銅・原油・地下水が見つかります。
- **チップ**
  9×9 の盤に弁と管を組み、1マスの部品として鋳込めます。チップの中にチップを入れることもできます。
- **社長として経営する**
  全27件の案件に難易度（★1〜5）があります。納期・純度・定時便・交互納品などの条件付き案件は、回路で解くパズルになっています。最上級の案件では、チップの設計図そのものを納めます。

## 基本ルール

1. **ボイラー**は水に隣接させ、燃料（石炭・木炭・灯油）を入れると、背後の管へ蒸気を送ります。
2. **設備**は、自分の背後を通る管から蒸気を受けて動きます。圧が低いと止まらずに遅くなります。
3. **管**は、ドラッグで引いた向きにだけつながります。隣に並べただけでは混ざりません。交差させたいところは交差管を使います。
4. **弁**は、背中（入口）から矢印（出口）へ蒸気を通します。
   - 常閉弁：横の操作口に圧があるときだけ開く
   - 常開弁：横の操作口に圧があると閉じる
   - 閉じた弁は、出口側の蒸気を抜く
   - 開閉には遊びがある（60% で入り、40% で切れる）
5. **案件**の品を出荷口へ届けると報酬が入ります。本筋の依頼を片付けると、新しい設計書が買えるようになります。

### 回路の例

| 回路 | 組み方 |
|---|---|
| NOT | 常開弁の入口に給気の線、操作口に入力 A をつなぐ |
| AND | 常閉弁の入口に A、操作口に B をつなぐ |
| OR | 2本の線を逆止弁を通して合流させる |
| XOR | 常開弁を2つ使う。（入口 A・操作口 B）と（入口 B・操作口 A）の出口を合流させる |

## 操作

| | PC | スマホ |
|---|---|---|
| 設置 | 左クリック（管・ベルトはドラッグで連続） | タップ／ドラッグ |
| 撤去 | 右クリック、または撤去ツール | 撤去ツール |
| 向きを変える | `R` | 右上の「向き」 |
| 管だけを見る | `Tab` | 右上の「管」 |
| 視点の移動 | `WASD`、または指ツールでドラッグ | 指ツールでドラッグ、2本指 |
| 拡大縮小 | ホイール | 2本指でピンチ |
| 指ツールに戻る | `Esc` | — |

レバー弁・振り子弁・秤弁・組立台・気送管は、指ツールでクリックすると設定を切り替えられます。

## セーブについて

進行はブラウザの localStorage に自動保存されます（8秒ごとと、タブを閉じたとき）。

- ブラウザのサイトデータを消すとセーブも消えます。
- 別のブラウザや別の端末とは共有されません。

## ローカルで動かす

`index.html` をブラウザで開くだけです。ビルドも依存ライブラリもありません。

```bash
git clone https://github.com/ISHIIYUTO11235/steam-works.git
cd steam-works
open index.html   # Windows は start index.html
```

## 技術

- 1ファイルの HTML（Canvas 2D、素の JavaScript）
- ドット絵はすべてコード内で描画（16px）
- 効果音は Web Audio API でその場で合成
- 蒸気網は、管のつながりを Union-Find でまとめた区画ごとに、圧と流量を 0.1 秒刻みで計算
